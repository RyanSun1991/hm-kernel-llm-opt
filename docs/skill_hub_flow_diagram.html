设计要点速记 / Design Tenets

  • 两类资产两台引擎 Two assets, two engines — 知识=追加+查重+冲突消解（绝不删历史）；技能=就地编辑+eval 严格变好（反喂安全）。
  • markdown 是唯一真相源 Markdown is the source of truth — 索引是派生缓存，可重建；一切可 git 评审。
  • 成员习惯零改动 Zero habit change — 正源就是大家已在写的 .opencode/memory/；新增的只是收口一条蒸馏命令。
  • 门禁 fail-loud、晋升建议制 Gates fail loud; promotion is suggest-only — 冲突即 CI 红；毕业永远由人合并。
