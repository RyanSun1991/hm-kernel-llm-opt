Diagram ① The Loop: how experience circulates

Members work as usual → one command at close-out → contribute via git PR → hub gates and curation → the next member benefits automatically.

Diagram ② Placement: what lands in which directory

One rule: a record's scope decides its directory (CI-enforced); anything file/function-level is knowledge, never a skill (skills have only three layers — core/technique/domain — so the tree can't explode).
