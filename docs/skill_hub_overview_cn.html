图 ① 主闭环：经验怎么转起来

成员照常干活 → 收口跑一条命令 → git PR 投稿 → 中央仓质检策展 → 下一个人自动受益。

②成员把候选包 cp 到 hm-skill-hub/staging/你/日期.jsonl，开 PR
③CI + 维护者CI 自动四道门；维护者看 central_curate.py 报告后定稿入库
④任何成员hmopt resolve "mm/vmscan.c::shrink_node"（研究新函数前跑）

图 ② 数据落位：什么东西落到哪个目录

一条规则：记录的 scope 决定目录（CI 强校验）；文件/函数级的东西永远是知识不是技能（技能只有 core/technique/domain 三层，杜绝目录爆炸）。
