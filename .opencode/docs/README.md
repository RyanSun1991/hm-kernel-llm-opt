# OpenCode Docs Conventions

Use this directory for living subsystem knowledge.

## Suggested files

- `[component]_design.md`: structure, API, control flow, concurrency
- `[component]_trace.md`: runtime evidence and hotspot interpretation
- `[component]_bootstrap.md`: reusable starting context for future sessions
- `harness_engineer_system.md`: control-plane roles, stage order, and handoff rules

## Minimum content

- subsystem boundary
- entry points
- important structs
- hot path
- concurrency model
- lifecycle constraints
- open questions
